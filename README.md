# AWS Cloud Infrastructure Lab

Hands-on AWS environment built to practice infrastructure configuration
and systematic troubleshooting — VPC, EC2, S3, and IAM, with documented
break/fix scenarios.

**Status:** in progress

## Planned
- VPC with public and private subnets, route tables, security groups
- EC2 instance with SSH access and a small service
- S3 bucket accessed through an IAM role
- Documented failure scenarios: security group misconfiguration, IAM
  permission errors, routing failures, and connectivity issues
- Troubleshooting runbooks for each scenario

## Stack
AWS (VPC · EC2 · S3 · IAM) · Linux
